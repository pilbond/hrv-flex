# Audits

Índice de revisiones y auditorías del repositorio.

Subáreas:
- `documentation/` para revisiones de documentos y contratos
- `session_analysis/` para auditorías del módulo analítico de sesiones
- `ssm/` para auditorías del bloque SSM
- `system/` para auditorías del sistema operativo global
- `tests/` para revisiones de contenido y utilidad de `tests/`
