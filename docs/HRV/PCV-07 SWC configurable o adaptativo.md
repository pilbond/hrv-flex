# PCV-07 SWC configurable o adaptativo

Estado: descartada

## Decision

La propuesta de parametrizar o adaptar automaticamente `swc_mult` no forma
parte del comportamiento vigente. El multiplicador SWC sigue gobernado por el
contrato actual de `build_hrv_final_dashboard.py`.

Esta nota conserva la trazabilidad de una idea evaluada, pero no debe
presentarse como backlog aprobado ni como capacidad parcialmente implantada.
Reabrirla requeriria una nueva tarea explicita, evidencia de falsos positivos
y actualizacion conjunta de codigo, tests y contratos del gate.
